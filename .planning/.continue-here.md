## Key insight (issue #7 root cause)
mdBook 0.5 injects its OWN sidebar numbers at runtime: `book/toc.js` renders
`<strong aria-hidden="true">1.</strong>` inside each chapter link — independent
of SUMMARY titles. The v1.0.3 SUMMARY strip was necessary but not sufficient.
Fix = CSS rule in `assets/zoom.css` (inlined at serve time by
`inject_vault_chrome`, so it applies WITHOUT vault refresh):
`.chapter-item a > strong[aria-hidden="true"] { display: none; }`
Test: `zoom_css_hides_mdbook_chapter_numbers` (tree.rs). 276 tests green, gate OK.
