<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator stdin → config.toml | Free-text answers (port, paths, email, password) cross into a file the server later trusts |
| config.toml on disk | Generated file stores the bootstrap admin password in plaintext |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Information disclosure | rpassword prompt | mitigate | Password read via rpassword (no echo, not written to stdout); acceptance criterion forbids echoing it |
| T-11-02 | Information disclosure | generated config.toml | mitigate | Plaintext bootstrap password is the LOCKED decision; generated file comment states it and advises chmod 600; value only bootstraps while the users table lacks the account |
| T-11-03 | Tampering | port input | mitigate | Port parsed as u16 with re-prompt on garbage — no arbitrary string reaches bind_addr |
| T-11-SC | Tampering | cargo installs | mitigate | Single new dependency rpassword (widely used, no transitive network surface); pin major version "7" |
</threat_model>
