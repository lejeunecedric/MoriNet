# PLAN 10-02 — MCP StreamableHttp on /mcp (rmcp)

**Type**: vertical slice (auth middleware → rmcp server → 4 tools → E2E tests). TDD mandatory.
**Depends on**: 10-01 (user_for_api_token).

## Objective

An MCP client (e.g. `mcp-cli`) can connect to `https://…/mcp` with
`Authorization: Bearer *** and discover/use 4 tools over the accessible vaults.

## Changes

1. `Cargo.toml` — `rmcp = { version = "3.7", features = ["server", "transport-streamable-http-server"] }`.
2. `src/mcp.rs` (new module) —
   - `struct MoriMcp { store, data_dir }` impl `ServerHandler` (`#[tool(tool_box)]`),
     stateless : the user of the current request is passed to the factory (see point 3) OR captured
     via a `RequestContext` — decide during implementation, otherwise stateless per-request with the claims
     injected by the middleware.
   - Tools (all ACL-scoped via `list_vaults_for` / `acl_allows`) :
     - `list_vaults()` → [{slug, name, scope}]
     - `list_notes(slug, path?)` → lists the `.md` files under the source (relative tree)
     - `read_note(slug, path)` → markdown content (safe_join, rejects `..`/absolute)
     - `search_notes(query, slug?)` → case-insensitive matches in the accessible `.md`
       files, [{slug, path, line, snippet}], reasonable cap (e.g. 50).
   - Tool errors (unknown vault/no access) : generic `ToolError`, no 403/404 distinction
     (no existence leak).
3. `src/server.rs` —
   - Bearer middleware on `/mcp` : `Authorization: Bearer *** → `user_for_api_token` ;
     missing/invalid → 401 JSON-RPC-ish. Session cookies are NOT accepted here.
   - Mounting : `StreamableHttpService::new(factory, LocalSessionManager::default().into(),
     StreamableHttpServerConfig::default().with_legacy_session_mode(false).with_json_response(true))`
     as `nest_service("/mcp", …)` — the factory captures a clonable handle (store pool).
   - The Bearer-authenticated user must reach the tools : in stateless mode, re-read the
     header in the handler via an ext layer that deposits the email in request extensions.

## Tests (RED first)

- Unit `src/mcp.rs` : `search_notes` over a temp corpus (fixture) — finds, case-insensitive,
  bounded ; `read_note` rejects `../` and paths outside the source ; `list_notes` sorts.
- ACL : a user without access to the slug gets a tool error on all 4 tools (fixture store).
- E2E (tower::ServiceExt oneshot on the router) : POST `/mcp` initialize + tools/list without
  Bearer → 401 ; with a valid Bearer → the list contains the 4 tools ; tools/call
  `list_vaults` returns only the accessible vaults.
