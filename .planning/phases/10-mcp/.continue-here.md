## Critical Anti-Patterns (do NOT repeat these)
- **Oublier le guard de version** : `src/lib.rs::version_matches_cargo_pkg_version` durcit la version — le bump **en même temps** que `Cargo.toml` à chaque release, sinon `check.sh` casse.
- **Binaire non portable** : ne jamais déployer sans `ldd target/release/morinet | grep ssl` clean (vendored-openssl le garantit, mais vérifier après tout changement de dep TLS).
- **Heredocs bash imbriqués** : les `\n` dans les scripts python via terminal cassent — écrire le script avec write_file puis l'exécuter.
