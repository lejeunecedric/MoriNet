## Critical Anti-Patterns (do NOT repeat these)
- **Forgetting the version guard** : `src/lib.rs::version_matches_cargo_pkg_version` hard-codes the version — bump it **at the same time** as `Cargo.toml` on every release, otherwise `check.sh` breaks.
- **Non-portable binary** : never deploy without a clean `ldd target/release/morinet | grep ssl` (vendored-openssl guarantees it, but verify after any TLS dependency change).
- **Nested bash heredocs** : `\n` in python scripts via terminal breaks — write the script with write_file then execute it.
