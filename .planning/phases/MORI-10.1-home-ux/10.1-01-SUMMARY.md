## Decisions
- Strongest-grant-wins semantics implemented via `Ord` on `Access` (`None < Read < Write`) rather than ad-hoc string compares — one rule for both `access_for` and `accessible_vaults`.
- Admin branch of `accessible_vaults` untouched: admins already see everything, shares add nothing.
- `hidden` only hides the row from the sharee's view; the owner's `list_shares` still shows it and re-sharing (upsert) clears it (T-10.1-05 accepted).
- Prune runs synchronously at boot (cheap DELETE on an indexed table), matching the `ensure_default_memberships` boot-sweep pattern.

## Lessons
- New `mod` blocks in store.rs must carry `#[cfg(test)]` or clippy `-D warnings` fails on dead code in the lib target.
- `cargo fmt --all` reformats drift in files outside the plan's scope — check `git status` after running it and revert out-of-scope churn.
- The single union point in `accessible_vaults`/`access_for` means web, WebDAV and MCP inherit share access with zero per-surface code (pitfall #14 avoided).
