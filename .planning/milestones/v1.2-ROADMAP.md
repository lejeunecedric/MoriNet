# Milestone v1.2: Team Access

**Status:** ✅ SHIPPED 2026-11-06 (released as `v1.3.0`, live on holldemo)
**Phases:** 15-17
**Total Plans:** 15 (5 per phase)

## Overview

Give a small team safe shared access to the same vaults: stop silent edit clobbering (strong ETags + conditional writes + upload conflict detection), expose everything read-only to machines (REST API with full MCP ACL parity), and let people in through their own identity provider (generic OIDC SSO coexisting with password login).

**Build order rationale** (all three researchers independently converged, see `.planning/research/SUMMARY.md`): ETag first (self-contained, no new deps, its `etag_of()` hash helper feeds the later phases), REST API second (pure reuse of MCP store queries, exposes Phase 15's ETags), OIDC last (only new dependency tree `openidconnect`, only migration, and the only change that can break login for existing users — lands on a stable base).

## Milestone Summary

**Key Decisions:**
- Replace-on-login group sync with absent-vs-empty claim distinction (resolved the ARCHITECTURE-vs-PITFALLS A5 research conflict; D-09/D-10)
- `user_identities` dedicated table over `users.provider` columns (D-11)
- REST responses are bare arrays/objects matching MCP field names; opaque base64 cursors; RFC 9457 errors (Phase 16 user decisions)
- `/api/v1` as standalone merged router — never under `require_session`; Bearer-gated catch-all instead of `Router::fallback` (Phase 16 plan-checker lesson)
- Auto-link only on `email_verified`, never to admin accounts (D-05/D-12)
- SSO callback ends byte-identically to `login_submit` — one session mechanism, zero middleware drift (D-02)

**Issues Resolved:**
- Real A6 session-confusion gap found by the security matrix (`a296562`): SSO state token could authenticate as a session — `verify_session` now rejects multiline payloads
- Anonymous audit-flood vector (REV-17-01): pre-parse callback denies no longer write DB rows
- Provisioned-account integrity: control-char emails refused before provisioning (REV-17-03)

**Issues Deferred:**
- 15-HUMAN-UAT: rclone/Obsidian real WebDAV smoke test (operator)
- 17-HUMAN-UAT: real-IdP smoke test (operator)
- G1-G3 composed E2E tests (SSO→API token→read; group-revocation direct test; shared-vault coexistence composition)
- REST access logging (blocked on `access_log.source` CHECK — folded into issue #10 scope)

**Technical Debt Incurred:**
- IdP discovery/JWKS uncached per request (REV-17-02)
- No `Secure` cookie attribute (pre-existing Phase 12 format; D-02 byte-identity forbids drift; TLS-terminated deployment)
- No `Cache-Control`/`Vary` on authenticated API responses; case-sensitive `Bearer ` prefix; fixed-window burst boundary (Phase 16 accepted)
- Nyquist VALIDATION.md absent for phases 15-17 (goal-backward VERIFICATION + SECURITY used instead)
