<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| vault HTML on disk → served bytes | Attacker-influenced book content (GitHub-sourced vaults) passes through the rewrite |
| stored theme value → HTML rewrite | A DB value is substituted into served page bytes |
| injected `<style>` snippet → visitor browser | Server-generated markup crosses into the DOM |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-10 | Tampering / XSS | theme rewrite | mitigate | Rewrite is a fixed-literal substitution: the ONLY mutated text is the quoted value inside `default_light_theme`/`default_dark_theme` assignments, and the value is whitelist-bounded server-side at write time (plan 12-02) to six fixed tokens — no attacker-controlled bytes are ever inserted; no path traversal surface (no file paths derived from the value) |
| T-12-11 | Tampering | visitor page content | mitigate | Exact-match replace only — visitor-authored content that merely mentions the literals is out of scope because the rewrite targets the two full assignment strings; unit test proves inertness when literals are absent |
| T-12-12 | XSS | injected `<style>` | mitigate | Static raw-string const with no interpolation (pitfall #25) — the keep-numbers snippet is byte-identical on every page; nothing user-controlled reaches it |
| T-12-13 | Denial of service | rewrite on large pages | mitigate | Two `str::contains` guards before any `replace`; non-UTF-8 payloads return untouched (existing behavior preserved); no regex engine |
| T-12-14 | Elevation of privilege | option pass scope | accept | Options apply only to pages served from the requesting user's accessible vault — no cross-vault path is introduced (call sites unchanged in authorization, only in data passed) |
| T-12-SC | Tampering | dependencies | accept | No new dependencies in this plan |

Block-on-high: any newly discovered HIGH threat in touched code blocks the plan. ASVS L1 applies.
